# TypeScript OOP Assignments
## Encapsulation, Abstraction and Interfaces

Assignments 1-5 are designed for progressive corporate training.

1. Bank Account - Encapsulation
2. Employee Payroll - Encapsulation
3. Payment Processing - Abstraction
4. Notification Service - Interfaces
5. E-Commerce Order & Payment System - Combined OOP

Each assignment contains:
- README.md
- starter/ boilerplate code

The starter code intentionally contains TODO sections and does not include the solution.
