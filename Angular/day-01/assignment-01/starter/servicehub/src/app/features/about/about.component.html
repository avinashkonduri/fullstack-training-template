ABOUT THE APPLICATION

Welcome to ServiceHub

ServiceHub is a sample corporate IT service management application built as an Angular learning project.

Our Purpose

Help employees submit support requests and help service teams organize, prioritize and resolve them.

For Employees

Submit requests, review request details, and follow the progress of support work.

For Support Teams

Review requests, coordinate assignments, and provide updates through a consistent workflow.

Angular learning note

This version intentionally uses static HTML content. Data binding and interactive behavior will be introduced in later lessons.
